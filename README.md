# Passa ou Repassa

Projeto didático do jogo **Passa ou Repassa**, desenvolvido em **C++ para Arduino Mega 2560**.

O objetivo é criar uma bancada interativa para atividades em sala de aula, permitindo que duas equipes participem de uma dinâmica de perguntas, respostas, pontuação e acionamentos físicos.

## Objetivos do projeto

- Desenvolver uma versão eletrônica do jogo Passa ou Repassa.
- Utilizar Arduino Mega 2560 como controlador principal.
- Trabalhar lógica de programação, eletrônica básica e automação educacional.
- Criar documentação técnica clara para montagem, manutenção e evolução do projeto.
- Permitir futuras expansões, como display LCD, placar digital, relés, sensores, buzzer e interface serial.
