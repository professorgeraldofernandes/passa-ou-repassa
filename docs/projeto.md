# Projeto — Passa ou Repassa

## 1. Visão geral

O projeto **Passa ou Repassa** consiste em uma bancada didática controlada por Arduino Mega 2560 para aplicação de dinâmicas educacionais com duas equipes.

A proposta é permitir que o professor conduza perguntas, respostas, repasses, pontuação e acionamentos visuais/sonoros de forma organizada e interativa.

## 2. Público-alvo

- Alunos de cursos técnicos.
- Estudantes de robótica educacional.
- Turmas de tecnologia, automação, eletrônica e programação.
- Atividades interdisciplinares envolvendo lógica, física, matemática e cultura maker.

## 3. Escopo inicial

A primeira versão do projeto deverá contemplar:

- Duas equipes: Azul e Vermelha.
- Botões de resposta para cada equipe.
- LEDs indicadores de equipe.
- Buzzer para sinalização sonora.
- Controle básico de rodada.
- Pontuação manual ou automática em etapa posterior.
- Estrutura de código modular para evolução.

## 4. Possíveis expansões

- Display LCD ou OLED.
- Placar com displays de 7 segmentos.
- Controle por botões do mediador.
- Banco de perguntas em cartão SD.
- Comunicação serial com computador.
- Interface web ou aplicativo auxiliar.
- Relé para acionamento de sirene, lâmpada ou efeito cênico.

## 5. Premissas técnicas

- O controlador principal será o Arduino Mega 2560.
- A linguagem principal será C++ no ambiente Arduino IDE.
- A montagem deverá priorizar segurança, manutenção simples e didática visual.
- O código deverá seguir boas práticas: nomes claros, constantes, funções dedicadas e comentários objetivos.
